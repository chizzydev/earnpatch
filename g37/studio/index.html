Installation
Bring the approved capability to Paperlane.
Paperlane is a separate reporting application on its own origin. Its backend calls the Bridge SDK. Access and paid-use checks run on Bridge, using the same approved SafeShare release.
const bridge = new BridgeClient({ url: BRIDGE_ORIGIN, key: SERVER_ONLY_KEY });
const capability = await bridge.capability(workspace);
const access = await bridge.access(workspace, session.customer);
const job = await bridge.prepare(workspace, session.customer, input);
const result = await bridge.run(workspace, session.customer, job.id, input);
The customer comes from your authenticated host session. Never put the integration key in browser JavaScript.
